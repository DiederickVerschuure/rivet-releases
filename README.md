# Rivet: game builds

Downloads for **Rivet**, an armoured-combat tank game (Windows and macOS).

## Download

Open the [latest release](https://github.com/DiederickVerschuure/rivet-releases/releases/latest) and download:

- **Windows:** `Rivet-windows.zip`. Unzip it into a folder of your own (for example `Documents\Games\Rivet`, **not** `C:\Program Files`) and run `Rivet.exe`.
- **macOS:** `Rivet-macos.zip`. Unzip it, move `Rivet.app` to your Applications folder, and open it from there. The first time, macOS may say it can't verify the app: right-click `Rivet.app` → **Open** → **Open**, or allow it under System Settings → Privacy & Security.

`checksums.txt` lists the SHA256 of each zip.

## Updates

Rivet checks this page when it starts and offers **UPDATE NOW** when a new version is out. It downloads, installs and restarts on its own. Your account, progress and settings are kept.

Players coming from itch.io: download the build here once; from then on the game updates itself.
